A notebook that remembers.

Write a few notes. Then pull the plug while it is still writing, or open it in a second tab. The notes are in the real ferrovec store: a Rust→WASM index written to this browser's private file system behind a checksummed write-ahead log. What this page acknowledges, it keeps.

Your notes

Each save is acknowledged only after its log record is on disk. The time shown is how long that took.

    Now try to lose them

    Each of these does something real to this tab or its files. The page measures what comes back.

    Pull the plug mid-write

    Saves 25 notes as fast as it can and reloads the tab partway through, with no close and no flush. The reload lands while a save is in flight.

    Crash during a checkpoint

    Checkpoints, saves 3 more notes, then reloads and leaves a half-written checkpoint file behind, the way a tab killed mid-checkpoint does.

    Open a second tab

    Both tabs share one store. One is elected leader; the other proxies through it. Close the leader and watch this tab take over.

    Start over deletes the store and the notes above.

    Find a note

    Nearest-neighbour search over the index, in this tab. With the instant embedder, search by words from the note; for meaning-based search see the search demo, which runs MiniLM vectors.

      Under the hood

      The store's files in OPFS, read by this page while the store is open. Two snapshot slots alternate; the log holds everything since the newest one.

      // The same three lines run this page (npm: ferrovec).
import { Ferrovec } from 'ferrovec';
const db = await Ferrovec.open('notebook');   // worker + model + OPFS
await db.insert('call the dentist tuesday');  // resolves once it is on disk
